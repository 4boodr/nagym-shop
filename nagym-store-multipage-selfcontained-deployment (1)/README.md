# NAGYM Multi-Page Storefront

This build preserves the latest NAGYM visual design and separates the website into:

- `index.html` — Homepage
- `men.html` — Men’s products
- `women.html` — Women’s products
- `about.html` — Brand story and community
- `cart.html` — Dedicated shopping bag
- `checkout.html` — Checkout preview

Upload every file in this folder to the root of the GitHub repository.
